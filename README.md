## About the Project

Finding job opportunities in today's competitive market is challenging. I built **TalentIQ AI** to help candidates improve their resumes, identify skill gaps, and prepare for technical interviews using Generative AI.

## STAR Method

**Situation** – Job seekers struggle with role-specific resumes, identifying skill gaps, and technical interview preparation.

**Task** – Build an AI-powered platform to simplify resume improvement and interview preparation.

**Action**
- Developed resume analysis using Python and FastAPI.
- Integrated PDF processing and role-based skill matching.
- Integrated Google Gemini API for personalized AI feedback.
- Built an interactive frontend using React.js.
- Deployed using Vercel and Render.

**Result** – Developed a working AI-powered platform providing resume feedback, skill-gap identification, and technical interview preparation support.
